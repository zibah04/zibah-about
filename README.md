# Hephzibah Momoh — Developer Portfolio

Personal website for **Hephzibah Onuh Momoh** ([@zibah04](https://github.com/zibah04)), featuring verified education/experience and an honest status overview of ten software projects and concepts. Written using HTML, CSS, and vanilla JavaScript, with mobile layouts, keyboard accessibility and category filters.

## Preview
Open `index.html` in any modern browser. No build step, API key, or package installation needed.

## Publish on GitHub Pages
1. Open **Settings → Pages** in this GitHub repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main**, **/(root)**, then **Save**.
4. Once GitHub confirms deployment, the expected website URL is **https://zibah04.github.io/zibah-about/**.

The URL is **not confirmed live** until Pages deployment has completed.

## Update
Change `projects` in `script.js` as projects are completed, and revise their status badges accurately. The site uses only public repositories; unfinished projects are marked as such.

## Privacy
No phone number, student records, home address or full CV document are included. The professional email, GitHub and LinkedIn links are drawn from the owner's 2026 developer CV.
